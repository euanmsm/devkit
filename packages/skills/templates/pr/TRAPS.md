# Manual-Checklist Traps

Ways a manual test step in **this** codebase looks correct and tests nothing.
Each entry should be a real step that shipped in a PR and failed on a tester.

**Every pr-qa workflow drafter and verifier reads this file in full.** When a tester catches
a bad step, add the trap here — the point is that each mistake happens once.

Each entry goes under a heading for its area, and says three things: the trap,
why the obvious step fails, and what to write instead.
